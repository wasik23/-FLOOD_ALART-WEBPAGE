ReliefOps ব্যবহার নির্দেশিকা

Flood Early Warning and Relief Support Platform

এই ম্যানুয়ালটি প্রেজেন্টেশনের জন্য ছোট ও সহজ ভাষায় লেখা। এখানে রিপো ক্লোন করা থেকে শুরু করে সব প্রধান ফিচার দেখানোর ধাপ আছে।

১. প্রজেক্ট ক্লোন

  1. GitHub রিপো খুলুন।
  2. টার্মিনালে চালান:

git clone https://github.com/wasik23/-FLOOD_ALART-WEBPAGE.git

cd -FLOOD_ALART-WEBPAGE

২. ইনস্টল ও রান

  1. প্যাকেজ ইনস্টল করুন: npm install
  2. ব্যাকএন্ড চালু করুন: npm run server
  3. নতুন টার্মিনালে ফ্রন্টএন্ড চালু করুন: npm run dev
  4. ব্রাউজারে খুলুন: http://localhost:5173

লাইভ ডাটা, SMS API, শেল্টার API এবং ডাটাবেস ফিচারের জন্য সার্ভার চালু থাকা দরকার।

৩. ডাটাবেস সেটআপ

  1. MySQL চালু করুন।
  2. server/.env.example কপি করে server/.env বানান।
  3. DB নাম, ইউজার ও পাসওয়ার্ড ঠিক করুন।
  4. ডাটাবেস তৈরি করুন: CREATE DATABASE reliefops;
  5. সিড ডাটা দিন: cd server তারপর npm run db:seed

৫. পাবলিক ফিচার

  • Home: বন্যা তথ্য, FFWC পানি লেভেল, খবর, যোগাযোগ।
  • Live Map: ঝুঁকি এলাকা, FFWC স্টেশন, help request, shelter, NGO, volunteer marker।
  • Request Help: কোনো অ্যাকাউন্ট ছাড়াই সাহায্য চাওয়া যায়।
  • SMS Alerts: মোবাইল নম্বর দিয়ে জেলা/উপজেলা ভিত্তিক সতর্কতা সাবস্ক্রাইব।
  • Donate: যাচাইকৃত donation account দেখা যায়।

৬. ম্যাপ ডেমো

  • রঙিন জেলা = flood risk level।
  • লাল/নীল/সবুজ circle = FFWC water station।
  • H = Help request location।
  • Home icon = Safe shelter।
  • N = NGO team location।
  • V = Volunteer location।
  • যেকোনো marker ক্লিক করলে বিস্তারিত দেখা যায়।

৭. Volunteer ফিচার

  • Volunteer home page থেকে registration করতে পারে।
  • Profile image, phone, guardian phone, address দিতে হয়।
  • Login করার পর availability, skills, task progress আপডেট করতে পারে।
  • Field report দিলে coordinator তা দেখতে পারে।

৮. NGO/Coordinator ফিচার

  • /ngo থেকে login।
  • Public help request review করা যায়।
  • Available volunteer assign করা যায়।
  • Volunteer field update দেখা যায়।
  • Records ও situation report page ব্যবহার করা যায়।

৯. Admin ফিচার

  • /admin থেকে login।
  • Dashboard: system health, database, FFWC status দেখা যায়।
  • NGO account create, edit, verify, ban, delete করা যায়।
  • District risk update করা যায়।
  • Broadcast alert দিলে alert database-এ save হয় এবং SMS send হয়।
  • Admin dashboard path: /admin/dashboard

১০. Real Data কোথায়

  • FFWC water level: external live API + server proxy।
  • Alerts: database-backed server API।
  • Shelters map: server API first, fallback demo data।
  • SMS subscriber: server file storage এখনো ব্যবহার করে।
  • Help request ও volunteer profile: এখনো local/demo storage; future database migration দরকার।

১১. প্রেজেন্টেশন ডেমো অর্ডার

  1. Home page দেখান।
  2. Live Map খুলে marker explain করুন।
  3. Request Help form submit করুন।
  4. SMS Alert subscription দেখান।
  5. Volunteer register/login দেখান।
  6. NGO login করে request assignment দেখান।
  7. Admin login করে broadcast alert দেখান।

১২. গুরুত্বপূর্ণ কমান্ড
